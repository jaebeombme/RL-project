## 보상·재현·한계

- 보상: 성공 +10, 실패 -5, 방출 후 거리 감소 ×0.4, 시간 벌점 0.1/s 유지. 토크 가중치 0 또는 0.5; 절대 기계적 일 가중치 0 또는 0.02/J. 설정을 결과에 맞춰 사후 변경하지 않았다.
- 제어 스텝 0.02s, 물리 스텝 0.002s, 최대2s. 재타격 허용 및 공 전체 림 하향 통과 성공 기준 유지.
- 가중치·optimizer·정규화의 warm start 없음. 100k/250k/500k/750k/최종 체크포인트를 각각 대응하는 정규화 파일과 로드했다. 마지막 성능만으로 비교하지 않으며 best checkpoint/seed 선택 없음.
- 동일 평가 목표를 고정 시점들에 재사용했으므로 학습 경과 진단용 고정 평가 세트다. 이후 튜닝한다면 독립 최종 테스트가 추가로 필요하다.
- 학습 seed는 3개뿐이며 일반적 통계 우월성을 주장하기 어렵다. 900개 에피소드를 독립 학습 반복으로 취급하지 않는다.
- 절대 기계적 일은 전기 소비 에너지가 아니다. 모든 비용은 에피소드 종료까지 적분한다.

## 결과 해석과 추가 점검

비용 없는 조건의 seed별 최종 성공률은 96.3%, 100%, 100%였다. 토크 조건은 96.3%, 0%, 0%로 학습 seed 의존성이 컸다. 기계적 일과 둘 다 조건은 최종 평가뿐 아니라 각 run의 전체 학습 Monitor에서도 성공 에피소드가 0개였다. 따라서 낮은 비용만으로 효율 개선을 주장할 수 없다. 현재 가중치와 학습 설정에서 성공 학습이 성립하지 않은 결과다. 비용 항이 성공 탐색을 억제했을 가능성은 다음 실험에서 확인할 가설이며, 원인이 단정된 것은 아니다.

탐색적으로 seed42의 none/torque가 함께 성공한 278개 목표를 비교하면 토크 조건은 시간 약 3.1%, 정규화 비용 약 18.5%, 절대 기계적 일 약 12.0% 낮았다. 그러나 이는 성공한 단일 seed에 조건부인 사후 분석이며, 나머지 두 torque seed 실패를 포함한 주 결과를 대체하지 않는다. exploratory-seed42-pair.json에 별도 기록했다.

후속 제안(아직 미실행): 비용 가중치를 낮춘 조건들을 다시 처음부터 학습하고, seed와 총 학습량을 동일하게 맞춘다. 현재 실험 설정·데이터는 결과를 보고 변경하지 않는다.
