# 제어 비용 추가 비교 실험

동일한 누적 1,001,472스텝 체크포인트에서 두 조건을 각각 1,000,000스텝 요청하여 이어 학습했습니다. PPO rollout 단위 반올림으로 실제 추가량은 아래 설정 파일에 기록했습니다. 토크 직접 제어, 자율 방출, 재타격 허용, 공 전체가 림 아래로 통과하는 성공 기준을 유지했습니다.

변경한 환경 설정은 정규화 토크 제곱 적분에 대한 보상 가중치(0 또는 0.05)뿐입니다. PPO 가중치·optimizer·관측 정규화를 동일하게 복원하고 RNG seed 42로 시작했습니다. CPU 스레드는 두 조건 모두 1개입니다.

평가는 학습 전 고정한 새 골대 위치 300개(기존과 동일한 위치 분포), 동일 초기화 seed, 결정론적 정책으로 진행했습니다. 평가로 체크포인트를 선택하지 않고 최종 모델만 사용했습니다.

## 세 모델 공통 성공 목표 278개의 동작 효율

| 조건 | 시간(s) | 제어 스텝 | 토크 제곱 적분(N²m²s) | 절대 기계적 일(J) |
|---|---:|---:|---:|---:|
| Initial 1M | 1.1389 | 57.38 | 61.728 | 25.886 |
| +1M, no effort cost | 1.0872 | 54.81 | 77.223 | 36.026 |
| +1M, effort cost | 1.0721 | 54.07 | 74.893 | 45.042 |

토크 제곱 적분은 제어 부담의 대리지표이며 에너지(J)가 아닙니다. 절대 기계적 일은 ∫Σ|τ·q̇|dt이며 실제 전력 소비량은 아닙니다. 모든 값은 에피소드 종료까지 측정합니다.

단일 학습 seed에 대한 탐색적 비교입니다. 300개 목표의 구간은 목표 표본의 불확실성을 나타내며 학습 seed 간 변동은 반영하지 않습니다. 공통 성공만 비교한 비용에는 해당 목표 집합에 조건부라는 한계가 있습니다. 전체 및 각 모델 성공 에피소드 평균도 comparison.json에 기록했습니다.

## 결과 해석

새 목표 300개에서 추가 학습한 두 모델 모두 300/300 성공했습니다. 세 모델 공통 성공 목표 278개에서는 제어 비용 추가 모델이 같은 추가 학습량의 대조군보다 동작 시간 약 1.4%, 토크 제곱 적분 약 3.0% 감소했으나 절대 기계적 일은 약 25.0% 증가했습니다. 원래 100만 스텝 모델 대비 두 추가 학습 모델 모두 토크 제곱 적분과 기계적 일이 증가했습니다. 따라서 현재 결과는 성공률 향상과 제한적인 토크 비용 감소를 보여주지만, 전반적인 에너지 효율 향상을 뒷받침하지 않습니다.

현재 보상은 정규화 토크 제곱 적분을 벌점으로 사용합니다. 절대 기계적 일은 측정만 하고 보상에는 포함하지 않습니다. 에너지에 초점을 맞추려면 이후 실험에서 기계적 일 항을 별도로 비교해야 합니다. 이번 실험에서는 사전 고정한 설정을 결과를 보고 변경하지 않았습니다. 300/300은 이 표본의 성공률이며 모집단 100% 성공 보장이 아닙니다.

보상에 실제로 사용한 정규화 토크 제곱 적분은 공통 278개 목표에서 대조군 대비 약 0.84% 증가했습니다. 관절별 토크 한계(8, 5 Nm)로 나누어 계산하므로 비정규화 토크 제곱 적분과 순위가 다를 수 있습니다. 따라서 이 실행은 벌점으로 지정한 비용의 개선도 입증하지 못했습니다. 비용 항을 넣었다는 사실과 비용 최소화가 실제 달성됐다는 주장을 구분해야 합니다.
